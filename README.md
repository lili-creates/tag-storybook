# Tag · Storybook

Storybook del componente **Tag** del archivo de Figma [One more tag](https://www.figma.com/design/14UVHNSOKWzMzBwGopIsmc/One-more-tag?node-id=8-525).

```bash
npm install
npm run storybook        # http://localhost:6006
npm run build-storybook
```

- Componente: `src/components/Tag/Tag.tsx` (+ `Tag.css`)
- Tokens claro/oscuro: `src/styles/tokens.css` (selector **Tema** en la barra de Storybook)
- Documentación (en español, a partir del Figma): `src/components/Tag/Tag.mdx`
- Iconos: [Phosphor](https://phosphoricons.com) cargados desde la CDN (`.storybook/preview-head.html`)
